# 02: 保留交互能力并补齐原生执行处理

**What to build:** 普通管道和 PTY 均保留持续 stdin，同时沿用或适配 Pi 原生 Bash 的成熟执行处理，避免遗漏环境、输出和清理细节。

**Blocked by:** None (can start immediately).

**Status:** completed

- [x] 逐项记录原生处理的来源、直接复用、必要适配或有意差异，不引入内部深层导入或修改 Pi。
- [x] 覆盖 Shell 配置、前缀、环境与命令 PATH、会话变量、启动错误、信号和取消、进程组清理、输出排空、UTF-8、净化、截断日志及 hooks。
- [x] 对发现的实际差异先补外部行为回归，再做最小修改。
- [x] 有效尾部输出不被固定排空截止时间丢弃；静默的继承管道不永久阻塞结果。
- [x] 保留主命令退出清理同组子进程、交接后取消不杀进程及背压输入顺序。
- [x] 无未解释的行为差异；已知限制与平台验证范围明确。

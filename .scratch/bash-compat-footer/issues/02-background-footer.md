# 02: 后台任务 Footer 数量与计时

**What to build:** async-bash 在现有 Footer 增加英文状态，例如 BG 2 · 3m 12s / 1m 05s。仅显示当前会话拥有或继承引用的真实运行中后台任务。

**Blocked by:** None (can start immediately). 本轮串行执行，在 01 后开始。

**Status:** done

- [x] 每个任务按实际启动时间计算总运行时长，包含前台 63 秒，按启动先后排列，每秒刷新。
- [x] 前台命令和 unknown 历史任务不计入后台数量；任务结束即移除，无后台任务时隐藏状态。
- [x] 可用宽度不足时保留完整时间项，末尾用 +N 表示省略项；不显示 ID。
- [x] 切换会话、继承引用、reload 和退出不串状态、不重复计时、不改变命令生命周期。
- [x] 使用 Pi 原生状态接口，不替换整个 Footer、不依赖 compact、不调用模型查询进度。
